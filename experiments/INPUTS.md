# Experiment inputs

This is the manifest of every input file read by the twelve experiments in `experiments/`. For each file it gives the hash, the size, whether it is in the repository, and where it comes from: how to download, build or request it if it is not in the repository.

- Hashes are full sha256 and sizes are in bytes (`sha256sum` and `stat -L -c %s`, following symlinks).
- Paths are repo-relative.
- **In the repository?** column: **Yes** means the file is in the repository. **If permitted** marks the NIS-seq channel matrices: they are fitted from spot-level base calls that the authors of Fandrey et al. (2025) shared on request, and are included only with their permission. If one is missing from your copy, rebuild it with `experiments/nisseq_error_analysis` ([below](#nis-seq-channel-matrices)). **No** means you download, build or request the file; [Inputs not in the repository](#inputs-not-in-the-repository) says how.
- λ uses the current convention, where λ = 1 is decode-only. File names from before 2026-09-11 use λ_old = 1 − λ.

## Synthetic experiments and the Fig 1b glyph: no data files

`synthetic_objective_correlation` (Fig 2a,b) and `synthetic_hvr` (Supp S1) read no data files. Their runners build candidate pools, scores and noise channels in memory from the config. Apart from the config, the only file they read is the shared stylesheet (last row of the table below).

`pep_grid_glyph` (Fig 1b) reads no data file either. Its values are illustrative placeholders written into the script.

## NIS-seq channel matrices

The NIS-seq matrices come from the NIS-seq error-analysis notebook, run with `SELECTED_PERCENTILE = 50` on the first N reads of each file. `experiments/nisseq_error_analysis` regenerates the three sizes and checks each against the matrices in the repository byte for byte, when your copy includes them.
- N = 5,000 gives the S3a panel and `*_pctl50_subsample5000`.
- N = 50,000 gives S3b: `*_pctl50_subsample50000`, whose first 10 rounds are in `ops_crispri_cross_eval/noise_matrices/`.
- N = 100,000 gives Fig 3d-f and S3c: `channels/archive/nisseq_hela_*_subsample.npy`.
- The notebook in `experiments/nisseq_error_analysis/` takes its paths from environment variables.
- Its inputs are the 32.9M spot-level base calls from the HeLa IL-1β screens E-9 and E-9C (Fandrey et al. 2025, Nat. Biotechnol., doi:10.1038/s41587-024-02516-5). Each fit uses only the first N reads of each tile-sorted file.
- The public NIS-seq data are on Zenodo, doi:10.5281/zenodo.13375079. The spot-level unfiltered base calls are **not** in that record: they are available from the authors of Fandrey et al. (2025) on request.
- The reads were matched to the Brunello library (Doench et al. 2016, doi:10.1038/nbt.3437).

The NIS-seq channel matrices are fitted from spot-level base calls that the authors of Fandrey et al. (2025) shared on request, and are included only with their permission. If one is missing from your copy, rebuild it with `experiments/nisseq_error_analysis` from the spot calls, which are available from those authors on request. The run writes `results/experiments/nisseq_error_analysis/subsample<N>/noise_matrices/nisseq_hela_{kind}_pctl50_subsample<N>.npy`, with `{kind}` = `uniform`, `positional`, `channel` or `positional_channel`. Put them where the configs read them. A copy without the matrices lacks these folders, so create them first from the repository root: `mkdir -p scripts/benchmark/noise_model_matrices/channels/nisseq scripts/benchmark/noise_model_matrices/channels/archive experiments/ops_crispri_cross_eval/noise_matrices`.
